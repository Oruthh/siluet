# Localization (I18N)

Siluet provides built-in support for internationalization (I18N), allowing you to easily build multi-language templates. Translations are stored in simple JSON files and accessed in your templates using a dedicated directive.

## 1. Directory Structure

By default, Siluet looks for translation files inside a `locales/` directory at the root of your asset loader path (e.g., `src/main/resources/theme/locales/`).

Each file should be named according to its language code (e.g., `en.json`, `pl.json`, `es.json`).

```text
resources/theme/
├── locales/
│   ├── en.json         # English translations
│   └── pl.json         # Polish translations
├── templates/
├── sections/
└── components/
```

## 2. Translation Dictionaries (JSON)

Inside your locale files, you can structure your translations using nested JSON objects. This keeps your translations organized by feature, component, or page.

**Example `locales/en.json`:**
```json
{
  "store": {
    "welcomeMessage": "Welcome to Siluet Tech Store!",
    "actions": {
      "addToCart": "Add to Cart",
      "checkout": "Proceed to Checkout",
      "viewDetails": "View Details"
    }
  },
  "errors": {
    "outOfStock": "This item is currently out of stock."
  }
}
```

### Key Flattening
When Siluet loads these JSON files, it **flattens** the nested structure into dot-notation keys. This means you don't have to write complex object traversals in your templates.

For example, the nested path `"store" -> "actions" -> "addToCart"` simply becomes the string key `"store.actions.addToCart"`.

## 3. Using Translations in Templates

To inject a translation into your HTML, use the `@t()` or `@translate()` directive followed by the flattened dot-notation key.

```html
<!-- components/productCard.html -->
<article class="product-card">
    <div class="card-body">
        <h3>{{ item.name }}</h3>
        
        @if(item.inStock) {
            <!-- Using the short alias @t -->
            <button class="btn-primary">
                @t("store.actions.addToCart")
            </button>
        } @else {
            <!-- Using the full directive @translate -->
            <p class="error-text">
                @translate("errors.outOfStock")
            </p>
        }
    </div>
</article>
```

## 4. Configuring the Render Context

Siluet determines which translation file to load based on the `Locale` provided to the render context in your Kotlin code. If you request `Locale.ENGLISH`, Siluet will attempt to resolve translations from `locales/en.json`.

```kotlin
import dev.siluet.Siluet
import dev.siluet.loader.ResourceSiluetAssetLoader
import java.util.Locale

fun main() {
    val siluet = Siluet {
        assetLoader = ResourceSiluetAssetLoader("theme")
    }

    val model = mapOf("name" to "Wireless Mouse")

    // Rendering with English locale (uses locales/en.json)
    val englishOutput = siluet.render("product", model) {
        locale = Locale.ENGLISH
    }

    // Rendering with Polish locale (uses locales/pl.json)
    val polishOutput = siluet.render("product", model) {
        locale = Locale.of("pl", "PL")
    }
}
```
